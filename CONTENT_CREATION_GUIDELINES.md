# The Universitas "Santaolalla-Veritasium" Content Framework
> **Version:** 1.0 (The Narrative Paradigm)
> **Zone:** Meta-Documentation

Esta academia repudia la enseñanza enciclopédica y el axiomatismo aséptico. Toda disciplina, toda ecuación y todo circuito no son verdades abstractas caídas del cielo platónico; son las cicatrices de una cruenta batalla histórica por la supervivencia teórica o material de la humanidad. Inspirados por la eficacia neurodidáctica de divulgadores como Derek Muller (Veritasium) y Javier Santaolalla, establecemos el siguiente patrón arquitectónico para la ideación y redacción de todo contenido dentro del Human Knowledge Graph:

## 1. Fase 1: La Pregunta Fundamental (El Conflicto)
Todo curso, módulo o video arranca obligatoriamente con una pregunta ontológica o gnoseológica insoslayable. Ningún documento empezará con la solución temática.
*   *Regla de Oro:* El cerebro no ancla conocimiento si no siente primero la crisis del vacío. Plantea la fractura histórica o teórica que asfixiaba a la sociedad.

## 2. Fase 2: El Cuadrilátero Histórico (Choque de Axiomas)
Se enfrentan las respuestas que la humanidad ha dado (El Eje X Universal). 
*   *Dogma Histórico:* Mostramos cómo una época estableció un axioma, y cómo la siguiente lo destruyó con otro, exponiendo las fisuras. Destacar el drama de los titanes (Ej: Kant vs Hume, Platón vs Aristóteles).

## 3. Fase 3: La Resolución Materialista (El Cierre Categorial)
Solo cuando la tensión narrativa sobre la necesidad del problema es insoportable, se presenta el formalismo académico riguroso (La Ecuación o el Teorema).
*   Se pulverizan los errores del pasado y se asienta la verdad científica/teórica actual (Materialismo).
*   Exige uso de `LaTeX` para matemáticas y `Mermaid` para grafos.

## 4. Fase 4: La Fractura Epistémica (El Salto)
La respuesta actual nunca es un callejón sin salida. Al resolver la pregunta, se genera inmediatamente una paradoja o pregunta que la disciplina actual no puede responder sola. Es el *cliffhanger* para el siguiente video.

## 4. Estructura de Markdown "Master Course"
Todo archivo de curso maestro (`_master.md`) seguirá este estricto *template*:
1.  **Metadatos Topológicos:** Nodo, Nivel, Prerrequisitos y Aperturas.
2.  **Epígrafe Narrativo:** Un breve párrafo poético/filosófico resumiendo trans-dimensionalmente qué se busca.
3.  **El Eje Histórico (Blockquote con 🕰️):** Un cuadro destacando el conflicto primigenio y el origen del pensamiento.
4.  **Desarrollo en Libros/Capítulos:** Teoría mezclada dialécticamente con el contexto empírico.
5.  **El Altar Bibliográfico Canónico:** Cita directa inmutable de los **Papers Oficiales Históricos** (con DOI, fechas precisas y contexto narrativo de las publicaciones), acompañados del texto didáctico moderno.
